## 🌐 Panduan Deploy ke GitHub Pages (100% Gratis Selamanya)

### Opsi A (Sangat Direkomendasikan — Alamat Web Utama)
Gunakan opsi ini agar nama website Anda rapi tanpa embel-embel nama folder:  
`https://USERNAME-GITHUB-ANDA.github.io`

1. Buat akun / Login ke [GitHub](https://github.com).
2. Klik tombol **New Repository**.
3. Beri nama repositori persis:  
   `USERNAME-GITHUB-ANDA.github.io`  
   *(Misalnya jika username GitHub Anda `fadiyahdesi`, beri nama `fadiyahdesi.github.io`)*.
4. Pilih **Public**.
5. Klik **Create repository**.
6. Di terminal PowerShell di folder ini, jalankan:
   ```powershell
   git init
   git add .
   git commit -m "feat: launch Fadiyah Desi Asmawati Backend Portfolio"
   git branch -M main
   git remote add origin https://github.com/USERNAME-GITHUB-ANDA/USERNAME-GITHUB-ANDA.github.io.git
   git push -u origin main
   ```
7. Tunggu sekitar 1–2 menit, portofolio Anda langsung aktif dan dapat diakses di:  
   `https://USERNAME-GITHUB-ANDA.github.io` 🎉

---

### Opsi B (Upload Langsung via Browser tanpa Git CLI)
Jika Anda belum menginstall Git di komputer:
1. Buat repository baru di web GitHub dengan nama `portfolio`.
2. Klik **uploading an existing file**.
3. Drag-and-drop file `index.html` dan `README.md` ke browser, lalu klik **Commit changes**.
4. Masuk ke menu **Settings** > **Pages** di repository Anda.
5. Di bagian **Branch**, pilih `main` dan folder `/(root)`, lalu klik **Save**.
6. Website akan tayang di: `https://USERNAME-GITHUB-ANDA.github.io/portfolio`.
